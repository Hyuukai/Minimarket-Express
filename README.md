##  Descripción

**Minimarket Express** es un proyecto de diseño web desarrollado para representar la identidad visual y la presencia digital de un minimarket. El sitio presenta de manera visual las diferentes categorías de productos, utilizando una interfaz sencilla, organizada y atractiva.

Este proyecto forma parte de la asignatura **Diseño Web I** y aplica principios de maquetación, jerarquía visual y organización de contenido.

##  Objetivo

Diseñar un sitio web informativo que permita presentar los productos y categorías de un minimarket de forma clara, moderna y fácil de navegar, priorizando la experiencia del usuario y la coherencia visual de la marca.

## 🚀 Cómo ejecutarlo

No requiere instalación ni dependencias: es un sitio estático.

1. Clona el repositorio:
```bash
   git clone https://github.com/tu-usuario/minimarket-express.git
```
2. Entra a la carpeta del proyecto:
```bash
   cd minimarket-express
```
3. Abre `principal.html` en tu navegador (o usa la extensión **Live Server** de VS Code para recarga automática).
